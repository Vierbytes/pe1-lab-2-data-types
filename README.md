# Lab 2: Data Types, Variables, Operators, and Basic I/O

This repository has one script for the profile and operator examples, one calculator, and the optional string exercise.

## `types_and_vars.py`

The script uses a string, integer, and float in its introduction. It also adds five to the age, multiplies the rectangle dimensions, and repeats a string.

```text
Hello, my name is Corey. I am 33 years old and 1.778 meters tall.
In 5 years, I will be 38 years old.
The area of a 5.5 x 2 rectangle is 11.0.
Python! Python!
```

The height value is 5 feet 10 inches converted to 1.778 meters.

## `simple_calculator.py`

Example run:

```text
Enter the first number: 7
Enter the second number: 3
Choose an operation (+, -, *, /): *
7 * 3 = 21
```

The script converts the two inputs to floats, checks which operation was selected, and reports invalid numbers, unsupported operations, or division by zero.

## `string_fun.py` (bonus)

Example run:

```text
Enter a word: Python
Length: 6
Uppercase: PYTHON
Repeated: PythonPythonPython
```

This part uses `len()`, `.upper()`, and string repetition with `*`.
